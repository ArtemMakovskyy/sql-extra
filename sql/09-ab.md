### 1. Funnel Conversion Rate Calculation

- **What we do:** Determine what percentage of users go from start to registration and purchase, and compare groups A and B.
    
- **How:** By dividing sums at different stages.
    
    - Step 1 (Visited site) — `SUM(value) WHERE event_name = 'session'`
        
    - Step 2 (Registered) — `SUM(value) WHERE event_name = 'new account'`
        
    - Step 3 (Purchased) — `SUM(value) WHERE event_name = 'session with orders'`
        

### 2. Comparing A/B Test Variant Effectiveness

- **What we do:** Determine which design/feature (Variant A or Variant B) brings more registrations and sales, and check statistical significance.
    
- **How:** Using `test` (experiment name) and `test_group` (A or B) fields. We group metrics by `test_group` and compare conversion differences.
    

### 3. User Behavior Analysis (Micro-conversions)

- **What we do:** Investigate which specific site actions (clicks, page views) lead to purchase, and which lead to churn.
    
- **How:** Using original events from the `events` table (`event_name` field may have values like `click_banner`, `add_to_cart`).
    

### 4. Segmentation (Finding Successful Audiences)

- **What we do:** Find out on which devices or in which countries the new design variant performed best (e.g., "in the US on iOS conversion increased by 15%, but in Europe on Android it decreased").
    
- **How:** Using `device`, `country`/`continent` (geography), and `channel` (traffic source: ads, search, etc.) fields.
    

### 5. Daily Metrics Monitoring (Dynamics)

- **What we do:** Check if something broke during the test and how user behavior changed over time.
    
- **How:** Using the `date` field. This allows building trend charts by day.
