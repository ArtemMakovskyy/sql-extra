DB Schema — Data Analytics

Created using AI Claude Sonnet 4.6

ТаблицяОпис
session сесіїГоловна таблиця. Кожен візит користувача = одна сесія з унікальним ga_session_id. До неї приєднується майже все інше.
session_params сесіїДеталі сесії: пристрій, країна, браузер, канал трафіку. Приєднується до session через ga_session_id.
event_params сесіїВсі дії користувача під час сесії (кліки, перегляди тощо). Одна сесія може мати сотні подій.
ab_test сесіїВ які A/B тести потрапила сесія і в яку групу (1=A, 2=B).
account підписникиПідписники які залишили email. Містить статус підтвердження пошти та чи відписався користувач.
account_session підписникиЗв'язкова таблиця між account і session. Показує в якій сесії користувач став підписником.
email_sent emailВсі надіслані листи. sent_date — це кількість днів після створення акаунта, а не реальна дата.
email_open emailКожне відкриття листа. Один лист може бути відкритий кілька разів.
email_visit emailКожен клік в листі. Може повторюватись для одного листа.
order покупкиПокупки. Кожен рядок = один куплений товар в сесії. Через item_id приєднується до product.
product покупкиДовідник товарів: назва, категорія, ціна. Не містить інформації про продажі — тільки характеристики.
revenue_predict фінансиПлан доходу компанії по датах. Для порівняння факту з планом.
paid_search_cost фінансиВитрати на платний трафік по датах. Для розрахунку ROI та ефективності реклами.
